# BDH Visualization Module

Publication-quality visualizations for BDH Science Fair Demo.

## Overview

This module creates compelling, high-DPI (300) graphs and charts for science fair presentations, demonstrating the BDH model's capabilities through visual storytelling.

## Features

- **Memory Retention Curves**: Shows 4× improvement in memory capacity
- **Training Speed Comparison**: Demonstrates 2.75× speedup with BBPE
- **Token Reduction Scatter Plot**: Visualizes efficiency gains
- **Training Loss Curves**: Shows convergence stability
- **State Matrix Heatmap**: Displays synaptic weight structure
- **Combined Poster Figure**: Multi-panel publication-ready figure

## Installation

All required libraries are already installed:
- matplotlib 3.10.7
- seaborn 0.13.2
- plotly 6.5.1
- numpy 2.2.6

## Quick Start

### Generate Sample Visualizations (Test Mode)

```bash
python visualization/visualize_results.py --test-mode
```

This creates all 6 visualizations using sample data in `visualization/`:
- `retention_curves.png` - Memory retention over sequence length
- `training_comparison.png` - Training throughput comparison
- `token_reduction.png` - Token reduction scatter plot
- `training_curves.png` - Training loss curves
- `state_matrix.png` - Synaptic state matrix heatmap
- `combined_poster_figure.png` - Multi-panel poster figure

### Generate from Real Data

```bash
# First extract data from checkpoints
python visualization/extract_viz_data.py --baseline checkpoints/baseline.pt --multiscale checkpoints/multiscale.pt

# Then generate visualizations
python visualization/visualize_results.py --results visualization/comparison_data.json
```

### Generate Only Combined Poster Figure

```bash
python visualization/visualize_results.py --combined-only
```

## Visualization Details

### 1. Memory Retention Curves

**Purpose**: Demonstrate the 4× improvement in memory capacity from multi-scale architecture.

**Data Format**:
```json
{
  "memory_retention": {
    "baseline": {100: 0.36, 500: 0.0065, 1000: 0.00004, 2000: 0.0},
    "multiscale": {100: 0.45, 500: 0.15, 1000: 0.05, 2000: 0.015}
  }
}
```

**Key Features**:
- Log-scale y-axis for exponential decay
- Color-coded lines with markers
- 4× improvement annotation
- Clear visual of effective memory limit

### 2. Training Speed Comparison

**Purpose**: Show 2.75× throughput improvement with BBPE tokenization.

**Data Format**:
```json
{
  "training_speed": {
    "Byte-level": 10000,
    "BBPE (8K)": 27500
  }
}
```

**Key Features**:
- Bar chart with value labels
- Speedup annotation with arrow
- Color-coded by tokenization method

### 3. Token Reduction Scatter Plot

**Purpose**: Visualize efficiency of BBPE vs byte-level tokenization.

**Data Format**:
```json
{
  "token_reduction": [
    {"text": "short", "byte": 19, "bbpe": 5},
    {"text": "medium", "byte": 150, "bbpe": 42}
  ]
}
```

**Key Features**:
- Scatter plot with color gradient
- Diagonal reference line
- Average reduction ratio annotation
- Individual text labels

### 4. Training Loss Curves

**Purpose**: Demonstrate training stability improvements.

**Data Format**:
```json
{
  "training_curves": {
    "Baseline (unstable)": [4.1, 3.8, 3.5, ...],
    "Stabilized config": [4.0, 3.7, 3.4, ...]
  }
}
```

**Key Features**:
- Raw data with transparency
- Smoothed curves (moving average)
- Shows convergence behavior
- Highlights instability vs stability

### 5. State Matrix Heatmap

**Purpose**: Visualize synaptic weight structure in BDH model.

**Features**:
- Viridis colormap for perceptual uniformity
- Grid lines showing modular organization
- Sparsity annotation
- Shows emergent structure

### 6. Combined Poster Figure

**Purpose**: Single multi-panel figure for posters/presentations.

**Layout**:
- Panel A: Memory Retention
- Panel B: Training Speed
- Panel C: Token Reduction
- Panel D: State Matrix

**Features**:
- Publication-ready (300 DPI)
- Panel labels (A, B, C, D)
- Consistent styling
- Suitable for printing

## Integration with Other Modules

### With Performance Analyst (T7)

The visualizer reads data generated by performance benchmarks:

```python
# In benchmarking code
results = {
    'memory_retention': {...},
    'training_speed': {...},
    'token_reduction': [...]
}

# Save to JSON
with open('visualization/comparison_data.json', 'w') as f:
    json.dump(results, f)
```

## Customization

### Modify Colors

Edit `BDH_COLORS` dictionary in `visualize_results.py`:

```python
BDH_COLORS = {
    'baseline': '#3498db',
    'multiscale': '#e74c3c',
    # Add your custom colors
}
```

### Adjust Figure Size

Modify `figsize` in each plotting function:

```python
fig, ax = plt.subplots(figsize=(12, 8))  # Width, height in inches
```

### Change DPI

Modify `savefig.dpi` in `plt.rcParams`:

```python
plt.rcParams.update({
    'savefig.dpi': 300  # High quality for printing
})
```

## Output Quality

All visualizations are saved at:
- **300 DPI** for publication/printing
- **PNG format** for compatibility
- **Tight bounding box** to minimize whitespace

For vector graphics (editable in Illustrator/Inkscape), modify save calls:

```python
plt.savefig('figure.pdf', bbox_inches='tight')  # Vector format
plt.savefig('figure.svg', bbox_inches='tight')  # SVG format
```

## Troubleshooting

**Issue**: Figures look blurry in presentation
**Solution**: Increase DPI to 300 or use PDF/SVG format

**Issue**: Labels overlap
**Solution**: Use `plt.tight_layout()` or rotate labels

**Issue**: Colors not distinguishable
**Solution**: Modify `BDH_COLORS` for better contrast
