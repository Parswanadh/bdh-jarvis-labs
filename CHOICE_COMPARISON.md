# 🚀 BDH Training Quick Start - Reasoning vs Shakespeare

## 📊 **Two Training Options**

### **Option 1: Shakespeare (Language Modeling)**
- **Task:** Generate Shakespeare-like text
- **Dataset:** Tiny Shakespeare sonnets
- **Training:** `python train_science_fest.py`
- **Demo:** "To be or not to be..."

### **Option 2: Reasoning (RECOMMENDED!)** ⭐
- **Task:** Solve math/logic problems
- **Dataset:** Math, logic, commonsense reasoning
- **Training:** `python train_bdh_reasoning.py`
- **Demo:** "What is 15 × 14? = 210"

---

## ⚡ **Quick Start (Choose One)**

### **For Shakespeare Training:**
```bash
conda activate bdh-fest
cd D:\projects\BDH
python train_science_fest.py
```

### **For Reasoning Training (RECOMMENDED):**
```bash
conda activate bdh-fest
cd D:\projects\BDH
python train_bdh_reasoning.py
```
