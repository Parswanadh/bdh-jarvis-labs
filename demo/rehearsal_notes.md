## Delivery Practice Checklist

### Voice and Speech
- [ ] Speak clearly and project
- [ ] Moderate pace (not too fast!)
- [ ] Vary tone for emphasis
- [ ] Pause before key points
- [ ] Pronounce technical terms clearly

### Body Language
- [ ] Stand comfortably (don't sway)
- [ ] Make eye contact with judges
- [ ] Use hand gestures naturally
- [ ] Point to screen (not just look)
- [ ] Face audience most of the time

### Technical Operation
- [ ] Navigate Jupyter smoothly
- [ ] Don't fumble with mouse/keyboard
- [ ] Know which cell comes next
- [ ] Have backup ready if cell fails

---

## Common Pitfalls to Avoid

### Timing Issues
❌ **Problem:** Section running too long
**Solution:** Have "fast forward" points marked in script

❌ **Problem:** Rushing through explanation
**Solution:** Practice speaking slowly, check timer

---

### Technical Issues
❌ **Problem:** Cell execution error
**Solution:** Have pre-generated output ready, switch to screenshots

❌ **Problem:** Jupyter crashes
**Solution:** Backup screenshots on USB, continue with narrative

---

### Delivery Issues
❌ **Problem:** Reading directly from slides
**Solution:** Know material well, use notes as guide only

❌ **Problem:** Turning back to audience too much
**Solution:** Practice side-body position to see both

❌ **Problem:** Speaking too quietly
**Solution:** Project voice, ask if back of room can hear

## Backup Plan Rehearsal

### Scenario 1: Jupyter Won't Start
**Action:** Switch to presentation slides with screenshots

**Practice:**
- [ ] Have screenshots ready
- [ ] Know which slide corresponds to which demo cell
- [ ] Practice narrative without live code
- [ ] "In the full demo, you would see..."

---

### Scenario 2: Cell Execution Takes Too Long
**Action:** Show pre-generated output, move on

**Practice:**
- [ ] Have output cells pre-computed
- [ ] Know when to cut and move on
- [ ] "Here's the result we'd see..."

---

### Scenario 3: Projector Not Working
**Action:** Gather around laptop, continue demo

**Practice:**
- [ ] Test projector beforehand
- [ ] Know if laptop screen is visible to group
- [ ] Have backup HDMI adapter

---

### Scenario 4: Model Won't Load
**Action:** Skip live generation, show visualizations only

**Practice:**
- [ ] Focus on graphs (which work)
- [ ] Explain conceptually
- [ ] "The model would generate..."
