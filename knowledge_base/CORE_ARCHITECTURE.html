BDH Master Class: Core Architecture

Welcome to the deep-dive into the BDH (Billion-Dimensional Hebbian) architecture. This document explores the mathematical transition from traditional quadratic attention to the linear-time Hebbian state mechanisms that allow for massive context windows and efficient memory retrieval.

Core Thesis: By replacing the Softmax kernel with a feature map and leveraging the associative property of matrix multiplication, we transform attention from a retrieval process over a sequence into a recursive update of a fixed-size state matrix.

1. The Transition: Softmax \(\rightarrow\) Linear Attention

Traditional Softmax Attention is defined as:

$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$

The \(\text{softmax}(QK^T)\) operation results in an \(N \times N\) attention matrix, where \(N\) is the sequence length. This leads to \(O(N^2)\) time and space complexity, creating a computational bottleneck for long contexts.

The Linearization Trick

To achieve \(O(N)\) complexity, we replace the softmax with a kernel feature map \(\phi(\cdot)\). If we can express the similarity between a query \(q\) and key \(k\) as a dot product of their feature maps \(\phi(q)^T \phi(k)\), the operation becomes:

$$\text{LinearAttention}(Q, K, V) = \frac{\sum_{j=1}^N (\phi(q_i)^T \phi(k_j)) v_j}{\sum_{j=1}^N \phi(q_i)^T \phi(k_j)}$$

2. The Feature Map \(\phi(\cdot)\)

The choice of \(\phi(\cdot)\) is critical for the approximation of the softmax kernel. In the BDH context, we utilize a non-negative activation map, typically based on a ReLU-based approximation or ELU:

$$\phi(x) = \text{ReLU}(x) \quad \text{or} \quad \phi(x) = \text{elu}(x) + 1$$

Following the Performer (Chou et al., 2021) framework, \(\phi(\cdot)\) must satisfy several mathematical properties:

  • Non-negativity: \(\phi(x) \ge 0\). This ensures that the state matrix \(E\) evolves monotonically, preventing the denominator from vanishing.
  • Kernel Approximation: \(\phi(q)^T \phi(k) \approx \exp(q^T k / \sqrt{d})\), recovering the "focus" of softmax attention.
  • Bounded Variance: The output is scaled to prevent exploding gradients during recursive summation.

3. The Associative Property & The State Matrix

The breakthrough in BDH comes from the associative property of matrix multiplication. In the linear formulation, we can regroup the terms:

$$\text{Output}_i = \phi(q_i)^T \left( \sum_{j=1}^N \phi(k_j) v_j^T \right)$$

The term inside the parentheses is independent of the query \(q_i\). We define this as the State Matrix \(E\):

$$E = \sum_{j=1}^N \phi(k_j) v_j^T$$

Now, retrieval is simply a vector-matrix multiplication: \(\text{Output} = \phi(q)^T E\). The complexity is now \(O(N \cdot d^2)\), where \(d\) is the feature dimension. Since \(d \ll N\) in long sequences, this is effectively linear in \(N\).

4. EMA Normalization

To ensure the output remains scaled similarly to softmax, we must normalize the retrieval. A simple cumulative sum for the normalization factor \(D_t\) leads to a vanishing signal as \(t \to \infty\) because the state \(E\) is decayed but \(D_t\) is not.

BDH implements Exponential Moving Average (EMA) Normalization. We apply the same decay rate \(\lambda\) to the normalization state:

$$D_t = \lambda D_{t-1} + \phi(k_t)^T \phi(k_t) + \epsilon$$

This ensures that the numerator and denominator decay at the same rate, maintaining a stable output magnitude across infinite sequence lengths. The \(\epsilon\) term is a small stabilizer to prevent division by zero.

5. Hebbian Memory Theory

The construction of the state matrix \(E\) is a direct implementation of Hebbian Learning. Donald Hebb's 1949 postulate, often summarized as "Neurons that fire together, wire together," suggests that the connection between two neurons is strengthened when they are activated simultaneously.

Mathematical Implementation in BDH

In BDH, the "firing" corresponds to the activation of the key \(\phi(k)\) and the value \(v\). The state matrix \(E\) acts as the synaptic weight matrix of a linear associative memory. Every new token \((k_t, v_t)\) performs a rank-1 update to the memory:

$$\Delta E_t = \phi(k_t) v_t^T$$

The memory is "written" by outer products and "read" by inner products. This allows the model to store associations in a compressed, fixed-size representation regardless of the input sequence length.

6. Multi-Scale Memory & The Physics of Decay

A pure Hebbian sum \(E = \sum \phi(k)v^T\) has no notion of time; it treats the first token and the thousandth token with equal importance. To model temporal dynamics and prevent memory saturation (interference), BDH introduces Exponential Decay.

The Decay Factor \(\lambda\)

We introduce a decay rate \(\lambda \in (0, 1]\). The update rule becomes:

$$E_t = \lambda E_{t-1} + \phi(k_t) v_t^T$$

This creates a Memory Horizon. The influence of a token \(j\) steps in the past is scaled by \(\lambda^j\).

Multi-Scale Weighting

A single \(\lambda\) forces a trade-off: a large \(\lambda\) remembers the distant past but is slow to adapt; a small \(\lambda\) adapts quickly but forgets. BDH solves this by maintaining multiple state matrices \(E_{\lambda_s}\) with different decay rates \(\lambda_1, \lambda_2, \dots, \lambda_S\):

$$E_{\text{total}} = \sum_{s=1}^S w_s E_{\lambda_s}$$

7. Hyperparameter Logic \(w_s\)

The weights \(w_s\) determine the contribution of each temporal scale to the final memory retrieval. These are not fixed constants but learnable parameters optimized via backpropagation.

The optimization objective for \(w_s\) is to balance the precision of local retrieval (low \(\lambda\)) against the stability of global context (high \(\lambda\)). During training, the model learns to dynamically adjust \(w_s\) based on the task complexity—assigning higher weights to long-term scales for document-level understanding and shorter scales for token-level syntax.

8. State Matrix Evolution

The evolution of the state \(E\) can be viewed as a dynamical system. The state at time \(T\) is the weighted sum of all previous inputs, decayed by their respective time offsets:

$$E_T = \sum_{t=1}^T \lambda^{T-t} \phi(k_t) v_t^T$$

This recursive evolution ensures that the model maintains a constant-time update cost per token, enabling the processing of millions of tokens while the "memory" remains contained within the dimensions of \(E\).

9. Multi-Resolution Memory (MRM)

While the Hebbian state \(E\) is powerful for long-term memory, it can suffer from "blurring" when extremely precise local dependencies are required. BDH reconciles this through Multi-Resolution Memory (MRM), utilizing a Saccadic Attention strategy.

  • The Syntactic Path (Softmax Window): Optimized for high-precision local dependencies and immediate token-to-token relationships. It leverages FlashAttention for hardware-native efficiency.
  • The Structural Path (Linear State): Provides \(O(N)\) global context and thematic persistence, preventing the "memory fade" typical of pure windowed approaches.

The final output is a gated reconciliation of both paths:

$$\text{Output}_{\text{final}} = \alpha \cdot \text{Attention}_{\text{local}}(q, K_{win}, V_{win}) + (1-\alpha) \cdot (\phi(q)^T E)$$

The gating factor \(\alpha\) is dynamically determined by a lightweight router based on the input's informational entropy, ensuring the model selects the optimal resolution for the current task.

10. Convergence & Stability

A critical concern in recursive state updates is the potential for numerical divergence as \(N \to \infty\). In BDH, the stability of \(E\) is guaranteed by the decay factor \(\lambda < 1\).

The state \(E_T\) is essentially a geometric series. Even as the sequence length grows infinitely, the norm of the state remains bounded:

$$\|E_T\| \le \sum_{j=0}^\infty \lambda^j \|\phi(k_{T-j}) v_{T-j}^T\| \le \frac{1}{1-\lambda} \max(\|\phi(k)v^T\|)$$

This convergence ensures that the memory does not "explode" and that the model reaches a steady state of information density, preventing the saturation that plagues simpler linear recurrence models.
