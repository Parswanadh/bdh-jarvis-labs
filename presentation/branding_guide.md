## Typography

### Font Families

#### Primary Fonts
- **Inter** (preferred) - Google Fonts, free
- **Roboto** (alternative) - Google Fonts, free
- **SF Pro** (Mac only)
- **Segoe UI** (Windows only)

#### Code Fonts
- **Fira Code** (preferred) - ligatures, free
- **JetBrains Mono** (alternative) - free
- **Consolas** (Windows fallback)
- **Monaco** (Mac fallback)

### Font Sizing

#### Presentation Slides (1920×1080 or 16:9)
- **Title**: 60-72pt (h1), 48-54pt (h2)
- **Body**: 24-32pt
- **Captions/Notes**: 18-20pt
- **Code**: 16-18pt (monospaced)

#### Poster (36"×48")
- **Title**: 72-96pt
- **Section Headers**: 36-48pt
- **Body Text**: 18-24pt
- **Captions**: 14-16pt
- **Code**: 14pt (monospaced)

#### Handouts/Reports
- **Title**: 28-32pt
- **Headers**: 18-22pt
- **Body**: 11-13pt
- **Captions**: 9-10pt
- **Code**: 10pt (monospaced)

#### Web/Digital
- **Title**: 2-2.5rem (32-40px)
- **Headers**: 1.25-1.5rem (20-24px)
- **Body**: 1rem (16px)
- **Captions**: 0.875rem (14px)
- **Code**: 0.9rem (14px, monospaced)

### Font Weights

- **Light**: 300 (rarely used)
- **Regular**: 400 (body text)
- **Medium**: 500 (subheaders)
- **Semibold**: 600 (headers, emphasis)
- **Bold**: 700 (titles, strong emphasis)

### Typography Rules

1. **Hierarchy**: Use size, weight, and color to establish hierarchy
2. **Limit fonts**: Maximum 2 font families (primary + code)
3. **Line length**: 60-75 characters maximum for body text
4. **Line height**: 1.5× for body text, 1.2× for headers
5. **Paragraph spacing**: 1.5× line height between paragraphs
6. **Never**: All caps for body text (hard to read)

## Visual Elements

### Logo/Icon

#### Dragon Logo Concept
The logo combines:
- **Dragon silhouette** - represents the "hatchling"
- **Neural network pattern** - brain-inspired AI
- **Circuit lines** - technology/engineering

#### Usage Guidelines
- **Minimum size**: 32px for digital, 1" for print
- **Clear space**: 1× logo height on all sides
- **Background**: Works on white, light gray, or dark blue
- **Don't**: Stretch, rotate, or modify proportions

### Icons

#### Icon Style
- **Style**: Flat, minimal, line art (2px stroke)
- **Size**: 24-48px for slides, scalable for poster
- **Color**: Use primary/accent colors consistently

#### Recommended Icon Sets
- **Heroicons** (free, MIT license)
- **Lucide** (free, ISC license)
- **Tabler Icons** (free, MIT license)
- **Font Awesome** (free for CC-BY)

#### Icon Mappings
- 🐉 Dragon/Bio-Hybrid → Custom or brain+chip icon
- ⚡ Fast/STP → Lightning bolt
- 🔄 Medium/LTP → Refresh/rotate
- 🧠 Slow/Structural → Brain
- 📊 Results → Chart/bar graph
- 💻 Code → Terminal/code icon
- 📈 Improvement → Upward trend
- ⚠️ Limitation → Warning triangle

### Graphics & Illustrations

#### Style Guide
- **Type**: Vector graphics (SVG/EPS preferred)
- **Line weight**: 2-3px for outlines
- **Corner radius**: 4-8px (soft, not harsh)
- **Color**: Use brand colors, no gradients
- **Shadows**: Minimal, subtle (0-2px blur)

#### Diagram Standards
```
Architecture Diagrams:
  • Boxes: Rounded rectangles, 4px radius
  • Lines: 2px stroke, gray (#64748B)
  • Arrows: Subtle arrowheads
  • Labels: 16-18pt, left-aligned
  • Spacing: 24px between elements

Flow Diagrams:
  • Nodes: Circles or rounded rectangles
  • Edges: Smooth curves (bezier)
  • Direction: Left-to-right or top-to-bottom
  • Labels: Along edges, centered

Comparison Graphics:
  • Split: Left/right or top/bottom
  • Alignment: Centered comparison
  • Scale: Consistent visual scale
  • Callouts: Arrow + label style
```

## Layout Principles

### Grid Systems

#### Presentation Slides (16:9)
- **Columns**: 12-column grid
- **Gutters**: 24px
- **Margins**: 48px on all sides
- **Safe area**: Keep content within 48px margins

#### Poster (36"×48" portrait)
- **Columns**: 3-column layout
- **Gutters**: 0.5" between columns
- **Margins**: 0.75" on all sides
- **Section spacing**: 0.5" between sections

#### Handouts (8.5"×11")
- **Columns**: 2-column layout
- **Gutters**: 0.25"
- **Margins**: 0.5" on all sides
- **Header/Footer**: 0.5" each

### Visual Hierarchy

1. **Primary** (First thing seen)
   - Largest size
   - Darkest/boldest color
   - Top/left position

2. **Secondary** (Supporting information)
   - Medium size
   - Supporting colors
   - Middle position

3. **Tertiary** (Details)
   - Smallest size
   - Lighter colors
   - Bottom/right position

### White Space

- **Generous**: Don't crowd content
- **Consistent**: Equal spacing between related elements
- **Breathing room**: At least 1.5× font size around text
- **Section breaks**: 2-3× normal spacing

## Data Visualization

### Chart Types

#### Line Charts (Trends over time)
- **Use**: Showing decay curves, retention over tokens
- **Style**: Smooth lines (not jagged)
- **Colors**: Compare series using accent colors
- **Grid**: Subtle horizontal lines only
- **Labels**: Axis labels, legend, values for key points

#### Bar Charts (Comparisons)
- **Use**: Comparing metrics across models
- **Style**: Horizontal bars (easier to read labels)
- **Colors**: Differentiate categories
- **Spacing**: 50% of bar width
- **Labels**: Value labels on bars, category on left

#### Comparison Tables
- **Style**: Clean borders, alternating row colors
- **Headers**: Bold, dark background
- **Alignment**: Left for text, right for numbers
- **Highlights**: Use accent color for key cells

#### Heatmaps (State matrices)
- **Colormap**: 'hot' or 'viridis' (colorblind-friendly)
- **Scale**: Normalized 0-1, show colorbar
- **Labels**: Axis labels, title
- **Annotations**: Call out interesting patterns

### Graph Guidelines

1. **Always label axes** with units
2. **Use consistent scales** across comparisons
3. **Show legends** clearly positioned
4. **Avoid chart junk** (unnecessary decorations)
5. **Colorblind-friendly**: Use patterns + colors
6. **High contrast**: Ensure visibility at distance
7. **Caption all figures**: What, why, takeaway

## Accessibility Standards

### Visual Accessibility

1. **Color Contrast** (WCAG AA minimum)
   - Normal text: 4.5:1 contrast ratio
   - Large text (18pt+): 3:1 contrast ratio
   - Graphics: 3:1 contrast ratio

2. **Colorblind-Friendly Design**
   - Never use red/green as only differentiator
   - Use patterns + colors for graphs
   - Test with colorblind simulators
   - Provide text labels for all colored elements

3. **Typography**
   - Minimum 18pt for slides (viewed from distance)
   - Minimum 12pt for handouts
   - Never rely on color alone to convey meaning

4. **Layout**
   - Logical reading order (left-to-right)
   - Consistent navigation/header structure
   - Clear section breaks

### Accessibility Checklist

- [ ] All text meets contrast ratios
- [ ] Color is not only means of communication
- [ ] Font sizes are readable at intended distance
- [ ] Images have alt text or captions
- [ ] Charts have text labels (not just color)
- [ ] Layout is logical and consistent
- [ ] No flashing/strobing content
- [ ] High contrast mode tested

## File Formats & Specifications

### Presentations
- **PowerPoint**: .pptx (compatible), embed fonts
- **Keynote**: .key (Mac), export to PDF for backup
- **Google Slides**: Link for sharing, export to PDF
- **PDF Backup**: Always have PDF version (fonts embedded)

### Posters
- **Source**: PowerPoint, Illustrator, or InDesign
- **Export**: PDF (print-quality), 300 DPI minimum
- **Size**: 36"×48" (portrait) or 48"×36" (landscape)
- **Color mode**: CMYK (not RGB)
- **Bleed**: 0.25" if needed

### Images/Graphics
- **Photos**: JPG (compressed), PNG (lossless)
- **Vector**: SVG, EPS (scalable)
- **Resolution**: 300 DPI minimum for print
- **Color**: sRGB for digital, CMYK for print

### Code Snippets
- **Syntax highlighting**: Use consistent theme
- **Font**: Monospaced (Fira Code, JetBrains Mono)
- **Background**: Light gray (#F8FAFC) or dark (#1E293B)
- **Export**: PNG with transparency or SVG

## Brand Voice & Messaging

### Tone
- **Professional**: Not casual, but not overly formal
- **Enthusiastic**: Show excitement about the work
- **Precise**: Use accurate terminology, define when needed
- **Confident**: Present with authority, admit limitations

### Key Messages

1. **BDH is the missing link**
   - Bridges Transformers and brain models
   - Unique interpretability + biology

2. **Multi-scale is the key insight**
   - Brain uses multiple timescales
   - We applied this to BDH with dramatic results

3. **We built this ourselves**
   - Clean implementation
   - 3 days of focused work
   - Reproducible and open

4. **Biological plausibility matters**
   - Helps understand intelligence
   - Enables interpretability
   - Path to better AI

### Phrases to Use
✅ "Our multi-scale approach..."
✅ "Inspired by neuroscience research..."
✅ "We demonstrated..."
✅ "Results show X times improvement..."
✅ "This maintains biological plausibility..."

### Phrases to Avoid
❌ "We revolutionized..." (overclaiming)
❌ "This is the best..." (subjective)
❌ "Obviously..." (condescending)
❌ "It's easy to see..." (might not be)
❌ "Perfect..." (nothing is perfect)

## Quality Assurance

### Pre-Presentation Checklist

- [ ] All colors match brand palette
- [ ] Fonts are consistent throughout
- [ ] Logo appears on title slide
- [ ] All images are 300 DPI+ (or vector)
- [ ] Charts have clear labels and legends
- [ ] Text is readable at 6 feet distance
- [ ] No typos or grammatical errors
- [ ] Slide numbering is correct
- [ ] Contact information is current
- [ ] QR codes are tested and working
- [ ] File is saved in native format + PDF
- [ ] Tested on presentation hardware

### Pre-Print Checklist (Poster)

- [ ] All above presentation checks
- [ ] Colors converted to CMYK
- [ ] Resolution is 300 DPI minimum
- [ ] Fonts are embedded or outlined
- [ ] Size is correct (36"×48" or 48"×36")
- [ ] Bleed is set correctly (if needed)
- [ ] Print proof reviewed at actual size or 25%
- [ ] Proofread by 2+ people
- [ ] QR codes tested at final size
- [ ] Contact information verified
